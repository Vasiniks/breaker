# Breaker

Yeast fermentation rig CAD and printable parts.

**Internal use only.** This repository is public for sharing/reference, but the documentation and contents are intended for internal use.

## Contents

- `cad/YeastRig/` — Fusion 360 design (`YeastRig.f3d`), Blender build script (`blender_build.py`), rig recipe, and exported STL print files under `print/`.
- `Yeast Fermentation Assignment - Copy.pdf` — assignment brief.

## Notes

- Print files are in `cad/YeastRig/print/` (STL).
- Regenerate the Blender model via `blender_build.py` + `rig_recipe.py`.
